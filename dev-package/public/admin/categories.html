Used by articles, but not in the list

These names appear on existing blogs but have no category row, so they are not offered in the editor's dropdown. Add one to bring it back into the list — the articles already using it are matched by name, so nothing about them changes.

How renaming works

An article stores its category as text, not a link — which is why a published post can never be broken by something that happens on this screen. The trade-off is that a rename has to be carried across, so renaming a category here also updates every article using it, and tells you how many were changed. Deleting a category leaves its articles exactly as they are; it only removes the name from the editor's dropdown.
