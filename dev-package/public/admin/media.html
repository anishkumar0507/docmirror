Where these live

Uploads go to Supabase Storage, not into the repository — the site's filesystem is read-only once deployed, so an image added here is available immediately without a deploy. Copy a URL to paste it into an article, or pick images from inside the editor. Deleting is permanent: if an article still points at the image, that article will show a broken picture, so the delete warns first and names the articles.
